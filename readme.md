# ASMR Downloader  
  
Simple Python script to download content from asmr.one mirrors.  
  
### Installation  
  
Tested on Python 3.13 but a lower version might work.  
  
The aiohttp module is required:
```
python -m pip install aiohttp
```  
  
### Usage  
  
Simply start the script.  
```
python asmr_downloader.py
```  
  
Input the code of whatever work you want to download.  
You'll be prompted to select what files you wish to download or not.
